--------Sequence Containers-------------


1-> vector
Access: O(1)
Insertion/Deletion at End: Amortized O(1)
Insertion/Deletion at Middle/Beginning: O(n)
Search: O(n)


2-> deque
Access: O(1)
Insertion/Deletion at End/Begging: O(1)
Insertion/Deletion in Middle: O(n)
Search: O(n)


3->Doubly Linked List
Access: O(n)
Insertion/Deletion: O(1)
Search: O(n)


4->Singly Linked List
Access: O(n)
Insertion/Deletion: O(1)
Search: O(n)






------Associative Containers---------

1->Set
Access: O(log n)
Insertion/Deletion: O(log n)
Search: O(log n)


2->map
Access: O(log n)
Insertion/Deletion: O(log n)
Search: O(log n)


-------------Unordered Associative Containers---------------


1->unordered_set
Access: N/A
Insertion/Deletion: O(1) on average, O(n) in the worst case
Search: O(1) on average, O(n) in the worst case

2->unordered_map
Access: O(1) on average, O(n) in the worst case
Insertion/Deletion: O(1) on average, O(n) in the worst case
Search: O(1) on average, O(n) in the worst case



-----------Container Adapters----------

1->stack
Access: O(1) for top
Insertion/Deletion: O(1)

2->queue
Access: O(1) for front and back
Insertion/Deletion: O(1)

3->priority_queue
Access: O(1) for top
Insertion: O(log n)
Deletion: O(log n)
Specialized Containers
std::bitset
Access: O(1)
Insertion/Deletion: O(1)
Search: O(n)
